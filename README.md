# OERNet FDM Templates

# OERNet-FDM-Templates

Dieses Repository enthält Templates für die Erstellung von OER-Bricks zum Forschungsdatenmanagement (FDM) im Markdownformat (*.md) zur Verwendung als [LiaScript](https://liascript.github.io/).
